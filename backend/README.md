# Backend - Kennedy Tech Solutions

Directorio reservado para los servicios de backend y API REST:
- Servidor Node.js / Express API REST.
- Modelos y controladores de base de datos.
- Configuración de servicios Cloud (Aiven / Supabase).

## Ejecutar localmente

Desde esta carpeta, instalá las dependencias e iniciá el servidor:

```bash
npm install
npm start
```

El servidor sirve también el frontend. Abrí `http://localhost:3000/solicitud.html`
para crear una solicitud. Si usás Live Server en el puerto `5500`, mantené el
backend iniciado en el puerto `3000`.
