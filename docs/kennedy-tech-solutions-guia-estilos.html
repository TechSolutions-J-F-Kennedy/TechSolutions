01 · Cómo usar esta guía
Esta página funciona como referencia visual del proyecto. Los equipos pueden reutilizar la paleta, tipografías, botones, formularios, tarjetas, estados, navegación e iconos. La idea es que las distintas pantallas de la aplicación se vean como partes de un mismo sistema.

16 · Reglas visuales para el proyecto

01 · Consistencia

Una misma acción debe verse igual en todas las pantallas. Evitar cambiar colores, formas o nombres sin motivo.

02 · Responsive

La Web Desktop prioriza tablas y paneles. La PWA prioriza tarjetas, botones grandes y navegación táctil.

03 · Estados claros

Usar los colores semánticos para diferenciar pendiente, progreso, éxito, advertencia y error.

04 · Acciones visibles

Las acciones principales deben ser fáciles de encontrar y tener un texto que explique qué hacen.
